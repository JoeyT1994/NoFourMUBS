# The native certifier's review (1 November 2026)

The report of a review of the native whole-ball certifier and its recognition argument. Read [`REVIEW.md`](REVIEW.md) first: it answers the sixteen questions of the review brief and
records one gap in the tree application (branch transport), closed by the overlap lemma of
[`subcell_overlap_lemma.md`](subcell_overlap_lemma.md). The annexes give the recognition proof
([`recognition.md`](recognition.md)), the symmetry bounds ([`symmetry_bounds.md`](symmetry_bounds.md)) and the cover
and contraction audit ([`cover_contractions.md`](cover_contractions.md)). Paths in these files refer to the review
package, not to this repository. What changed as a result is summarised in [`../NATIVE_REVIEW.md`](../NATIVE_REVIEW.md).
