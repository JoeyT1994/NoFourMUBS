F_out prunes at levels 9–11 drop by about 1.3 M in total.

**Cause:** `d0_test` (`Certification/domain.jl:37`) maps *any* `ErrorException` from `hplus_tm` to
`:singular`. The driver records that as `:D0_singular`, which is a branch‑layer cell. A guard failure
(`error("invariant: …")`) is an ErrorException. So wherever the guarded Taylor model of H₊ leaves the
proved range, the cell goes to the layer. The unguarded run pruned those cells with arithmetic that the
theorem does not cover. That is exactly the rigour gap the guard closes.

**Soundness:** the change is conservative. Every exception path in the driver becomes "not excluded":
`f_test`, `r_test` and `d0_test` return `:maybe`, `:singular` is a layer cell, and certify exceptions
give `ok = false`. No cell was pruned on the strength of a guard failure. All old layer cells are still
layer cells. The work set is essentially unchanged, so the certification cost estimate stands.

**Consequence for the branch layer:** there are 406,719 extra layer cells, mostly at level 9, plus the
first layer cells ever at levels 10–11. The layer prune (job 7140424) will show how many survive the
radical‑free side test. In the old run 4.4 % survived (623,187 of 14.02 M). Outcomes for the extra
cells may differ, because they are not all near R = 0.

## Where the guard fires, and a fix (study only, production unchanged)

The traceback on the sampled cells points to FastTM `inv`, called from `cdiv_tm` in `side_tm`
(`fasthplus.jl:54`). `inv` builds its Taylor coefficients as (−1)^k / c₀^(k+1). With a small but
nonzero centre c₀, the constant 1/c₀^(Q+1) exceeds 2⁴⁰, although x = H/|c₀| < 1 holds and the
result would be modest. `sqrt` builds √c₀·b_k / c₀^k in the same way.

A rescaled form uses the same guarded primitives and the same geometric‑tail lemma, with the centre
normalised to 1:

    1/(c0+h)   = (1/c0) · [ Σ_{k≤Q} (−u)^k + tail ],   u = h/c0 (TM times the interval 1/c0),
                 |u| ≤ x = hbound(1+u) < 1,  |tail| ≤ x^(Q+1)/(1−x)
    sqrt(c0+h) = sqrt(c0) · [ Σ_{k≤Q} b_k u^k + tail ],  |tail| ≤ |b_{Q+1}| x^(Q+1)/(1−x)

Every intermediate value is then O(1/|c₀|). The prototype, samples and results are in
[`guard_study_2026-09-30/`](guard_study_2026-09-30/): `scaled_intrinsics.jl`, `guard_study.jl`,
`sanity.jl` and `results/*.jsonl`. `scaled_intrinsics.jl` redefines the methods only inside the study
process. On four test models the rescaled `inv` and `sqrt` give the
same enclosures as the originals, to the digits printed, and 2,000 random points each lie inside both.
