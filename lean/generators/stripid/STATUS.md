signed corner sums (`PRM/CoverageSigned*.lean`, generator `lean/generators/strip/signed.py`;

## Method
1. Row scaling `s = t = 1` (`CoverageStripIdFormal`: `fData`, `fData_mom_scale`, `momentPoly_scale`,
   `halves_scaled`).  Return K's weighted sum reuses it (`CoverageSignedGauge.halves_scaled_w`).
2. The two halves become `QF` circuits in `(z | X, Y)` with `ζ = r s/t` (`CoverageStripIdQF`, `CoverageStripIdHalf`).
3. Kernel checks compare these circuits with reduced data generated by the scripts here.
4. The modulus relation `G = 0` enters through one explicit quotient polynomial `q2C`.
