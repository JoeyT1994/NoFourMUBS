# Diagnostic scope

These logs are not accepting certificates. Zero-width point successes do
not certify any positive-radius box. Floating excesses are proposal
measurements, never acceptance tests. Failed covers and failed experimental
models are inconclusive.

The production point tests use the same 16 exact centres from an earlier
open frontier of representative (1,2,5,4). With the old regional tubes,
5/16 closed and 11/16 failed tube bounds despite separated roots. The
stronger regional tubes close all 16 points with the outward kernel at
192 bits. Whole guarded cubes require the separately replayed partitions.

Exact seed collision/denominator results are regenerated by structural.py
and included in the clean receipt. The proposal, square-root switching
and physical-tau recentering experiments did not close the tested F3 box
within their budgets; none of these experimental modifications is used
by the delivered kernel.


The final transfer-point probe samples eight exact frontier centres in
each of production representatives 4 and 7 after the 900-second runs.
Before minimax row-phase refinement, with radii 1/34 and 1/28, all eight points for representative 4 close;
six of eight for representative 7 close. The broader search (eight
proposal charts in each orientation, plus strong-cell snaps) still fails
the other two points. The stored best tested projector-distance lower
bounds strictly exceed the tested radius squared for both unresolved
pairings. This rules out those specific reference tests at those points;
it is not a globally minimized distance to the whole Fourier family and
not proof that every alternative reference or certificate must fail.

The larger-common-ray-radius graph trials at rho=3/16, 19/100 and 5/26
failed necessary-graph clique tests. They are not adopted. A graph-test
failure is not the existence of a quartet.


Minimax row-phase refinement subsequently closes both of those points with
the same proved tube radii. All 16 frontier point controls then pass. This
resolves the specific proposal limitation; it is not a full-cube proof.
The final v2 controls explicitly repeat the two formerly failing points
with minimax enabled, then replay the frozen exact reference phases with
optimization disabled. The larger-common-ray graph failures above remain
inconclusive and unused.

A separate direct-Laurent R-cap trial reduced the F3 patch caps by factors
of about 5 to 14 but still hit the 3,000-label limit on all four patches.
This experiment is not adopted as an accepting alternative.

A child-level rechart trial, restricted to nodes with all four pairings
open, tried each F3 patch for 30 CPU-seconds. None closed; its partial
acceptances are not incorporated in the delivered forests. The changed
chart-selection rule is not adopted.
