# Retained verification

Every proved result in [ProvenResults](../ProvenResults/README.md) has its replay receipt here.

**Replay everything.** Run `python3 verify.py` from the project root. It copies the retained
reconstruction and result library into a temporary directory and runs every registered check (81 on 30 September; EffectiveConfinement was added after the latest complete run and passes alone).
It then writes one log per check and `summary.json` to the output directory:
- `--output-dir` chooses where they go (the default is this folder);
- `--jobs N` sets the parallelism;
- `--only NAME ...` runs a subset.

The cluster-cover checks also need Julia and the pinned campaign environment.

**Latest complete run:** [root_run_2026-09-30/](root_run_2026-09-30/summary.json), finished on
30 September 2026 with `--jobs 8` locally.

- `count_two` failed only its `collisions_and_five_value` time budget (60 s; it took 6.9 s on
  29 September) under the parallel load. It **PASSES** when rerun alone, in 48 s:
  [root_run_2026-09-30_count_two_rerun/](root_run_2026-09-30_count_two_rerun/summary.json).
- The longest checks are `fourier_practical_tube` (27 min) and `fourier_zero_neighbourhood` (23 min).

## Receipt notes (chronological)

These are the notes written as each receipt was added. Check counts quoted inside them are the
running totals at the time.

Run python3 verify.py from the project root. The runner copies only the retained
reconstruction and result library into a temporary directory, executes 69
checks, and writes logs and summary.json here.

retains paired real-cell runs and frozen Julia sources. The registered

actual Fourier rays, preservation of an actual 6+6 graph configuration,
and complete box membership under label partitioning. Full timing runs
are separate from that quick correctness check.

and requires its pinned Julia environment; see the
[replay instructions](../ProvenResults/CommonRays/ClusterCover/README.md#replay).

dependencies recorded in its proof.
