EXACT REPLAY
From this directory run:

    python3 -S verify_all.py

Python 3.10 or later is required; this package was replayed with Python 3.12.
Only the Python standard library is used. There is no network access or
third-party package requirement. Do not use Python's -O or -OO options.

The runner first checks SHA256SUMS and the complete file inventory, excluding
Python cache directories. It copies the package to a temporary directory,
removes the copied expected receipts, runs all six gates, and compares every
regenerated receipt byte for byte with the supplied receipt. The delivered
package is not modified. Temporary replay files are removed on exit.

VERIFICATION BOUNDARY
The gates verify exact finite arithmetic and symbolic polynomial identities
stated in their receipts. They do not formalize every written proof, replay
the upstream literature, enumerate the unresolved six-orbit cliques, or
certify a global A/C/F/F-prime theorem. There is no new Lean/kernel replay.
No atlas, Stage C output, or global no-four theorem is used in the new work.

The four-ray fixture uses a Fourier-free Dita anchor with known Fourier
companions. Its finite symmetry orbit is declared explicitly and is not
claimed to exhaust the common-ray fibre. The all-minor normalization fixture
is an arbitrary nonsingular-minor matrix, not a Hadamard sample; the general
identity is supplied by symbolic determinant arithmetic and the written
enumeration.

SHA256SUMS covers every delivered file other than itself.
